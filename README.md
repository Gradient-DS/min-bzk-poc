# min-bzk-poc

Proof-of-concept voor het Ministerie van Binnenlandse Zaken (gemeenten Leiden en Utrecht) voor het automatiseren van bezwaarschriftverwerking voor parkeerboetes via een soeverein, modulair multi-agent AI-systeem.

Het systeem combineert een orchestrator-agent met gespecialiseerde agents voor contextverzameling (graph RAG), metadata-extractie en compliance-checks, met een mens in de loop bij elke kritische stap. De POC draait op open-source modellen op Nebul-infrastructuur en is opgezet als een herbruikbaar artefact voor andere gemeenten.
